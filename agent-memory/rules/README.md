# Rules

Short, imperative rules, one per bullet. Change only after review.

- [documentation.md](documentation.md) — English documentation, file purpose at the top of each code file, task comment above every function.
- [tests.md](tests.md) — Run all tests before committing; commit only when the tests are green.
- [commits.md](commits.md) — Conventional commit messages: `type(scope): header` of about 50 characters, body lines at most 50 characters.
